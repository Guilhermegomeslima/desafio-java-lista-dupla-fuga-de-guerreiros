# desafio-java-lista-dupla-fuga-de-guerreiros
Implementação em Java de Lista Duplamente Encadeada através do minijogo 'Fuga de Guerreiros' (Guan Yu &amp; Magoichi Saika). Contém operações essenciais e algoritmos avançados de reamarração de ponteiros, como remoção de nós em posições alternadas, inversão e intercalação de listas sem criar novos nós.
